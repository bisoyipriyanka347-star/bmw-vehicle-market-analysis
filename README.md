# BMW-Vehicle-Market-Analysis
End-to-end Data Analyst project using SQL for data cleaning &amp; transformation and Power BI for interactive dashboard visualization. Analyzes BMW vehicle listings to uncover pricing trends, mileage impact, and engine performance insights.
# BMW Sales & Price Analysis

## 📌 Project Overview
This project analyzes BMW vehicle listings using SQL and Power BI.

## 🛠 Tools Used
- SQL (Data Cleaning & Querying)
- Power BI (Visualization & Dashboard)
- Excel (Initial Exploration)

## 📊 Key Insights
- X7 & 8 Series are most expensive
- Price increases with engine size
- Medium mileage cars show higher average price

## 📁 Files Included
- bmw.csv
- BMW_DASHBOARD.pbix
